# Braosei Studios — Session Booking Platform

Official session booking system for **Braosei Studios** in Takoradi, Ghana.

## Features
- Direct photography session booking
- Paystack 30% deposit integration (Mobile Money & Card payments)
- Automated confirmation and session prompts
- Operations dashboard and client CRM

## Location & Contact
- **Studio Address**: Braosei Studios : F. W. H Migeod Avenue, Takoradi, Ghana
- **Instagram**: [@braoseistudios](https://instagram.com/braoseistudios)
